# MVP 実Firebase E2E チェックリスト

このチェックリストは、MVPリリース前に **本番Firebase環境**（`smatournament-ce785`）で大会を最後まで完走できることを、運営者が画面操作だけで確認するためのものです。

## 事前準備

| 項目 | 内容 |
|------|------|
| 公開URL | https://smatournament-ce785.web.app/ |
| ログイン | トップページの「運営ログイン」から、運営者アカウントでログイン |
| テスト大会名 | 大会名の先頭に `[E2E]` を付ける（例：`[E2E] Single 3`） |
| テスト後 | 確認が終わった `[E2E]` 大会は削除してよい |
| Firestore確認 | Firebase Console → Firestore → `tournaments/{大会ID}` を別タブで開いておく |

### 共通の最初の操作（各大会で繰り返す）

1. トップページでログインする
2. 「**新しい大会を作成**」を押す
3. 大会情報を入力し「**大会を作成**」を押す
4. 作成された大会のカードをクリックし、**大会管理（ダッシュボード）** を開く
5. 「**エントリー受付を開始**」を押し、確認ダイアログで開始する
6. 「**公開ページを有効にする**」（トグル）をオンにする
7. 「**エントリー管理を開く**」からチームを登録・承認する  
   - 公開エントリーURLから申込 → 管理画面で「**参加承認**」でも可
